# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**CleanSnap** operates completely offline and handles local file deletions. We prioritize data integrity and safe filesystem operations above all else.

If you discover a potential vulnerability, data loss edge case, or privilege escalation:
1. **Email:** Send your report to `atpadkarmaruti@gmail.com`.
2. **Subject:** `[SECURITY] CleanSnap Vulnerability Report`
3. **Include:**
   - Affected platform (Windows or Android).
   - Detailed step-by-step reproduction instructions.
   - Sample file paths or directory structure that triggered the flaw.

### Timelines
- **Acknowledgment:** Within 24 hours.
- **Resolution & Fix:** Within 72 hours.
